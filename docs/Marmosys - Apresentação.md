# Sobre o Sistema

- Sistema ERP completo
- Desenvolvido especificamente para o setor
- Tecnologias modernas
- Interface intuitiva
- Integração total entre módulos

---

# Stack Tecnológica

- **Backend:** Laravel 10.x
- **Frontend:** Materialize CSS
- **Banco de Dados:** MySQL
- **Cache:** Redis
- **Servidor:** Nginx/Apache
